6Method

How every number here is derived

Nothing on this page is a hardcoded result. The package ledger holds four inputs per package — BAC, PV, EV, AC — and everything else is computed: 

SV  = EV − PV                 schedule variance, in dollars
CV  = EV − AC                 cost variance, in dollars
SPI = EV / PV                 <1 behind schedule
CPI = EV / AC                 <1 over cost
EAC = BAC / CPI               forecast at completion, at current efficiency
VAC = BAC − EAC               forecast over/(under) run

Portfolio EAC is rolled up bottom‑up as the sum of package EACs, because each package is its own control account with its own cost efficiency. The independent check — portfolio BAC / CPI — is shown alongside it. The two legitimately differ: a single blended CPI hides the spread between packages, and that spread is exactly what a program manager needs to see. Where they diverge sharply, the mix has shifted.

7Glossary

Plain language

BAC — Budget at Completion
The approved total budget for the scope. The baseline you are measured against.
PV — Planned Value
What the baseline said you should have earned by now.
EV — Earned Value
The budgeted value of work actually completed. Physical progress, priced.
AC — Actual Cost
What was really spent to earn that value.
SPI — Schedule Performance Index
EV ÷ PV. Below 1.00 means work is arriving slower than planned.
CPI — Cost Performance Index
EV ÷ AC. Below 1.00 means each dollar is buying less than budgeted.
EAC — Estimate at Completion
Forecast final cost if current efficiency holds.
VAC — Variance at Completion
BAC − EAC. Negative is a forecast overrun.
Total float
Days an activity can slip before it delays program completion. Negative float means it already does.
Exposure
Probability × cost impact. Makes unlike risks comparable, and comparable to contingency.
